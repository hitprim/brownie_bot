# Домовой

Telegram-бот, который помогает по двум бытовым темам: **что приготовить** и **что делать, когда дома что-то сломалось**.

Можно писать текстом или присылать голосовые — бот сам распознаёт речь, понимает, о чём вопрос, при необходимости уточняет детали и даёт конкретный практический ответ. Не «можно попробовать X или Y», а готовый рецепт с шагами или пошаговая инструкция по ремонту.

Бот: [@brownie_answ_bot](https://t.me/brownie_answ_bot)

## Что умеет

**🍳 Кулинария**
- Подбирает 2–3 рецепта под продукты, которые есть под рукой
- Учитывает время, порции и ограничения
- Подсказывает, чем заменить недостающий ингредиент

**🔧 Быт**
- Определяет тип проблемы: сантехника, электрика, техника, уборка и т.д.
- Задаёт уточняющий вопрос, если ситуация неоднозначна
- Даёт пошаговое решение для новичка
- Честно говорит, когда лучше вызвать специалиста — и какого
- Подсказывает, как избежать повторения

Для опасных ситуаций (электрика под напряжением, газ) бот не советует чинить самому, а отправляет к мастеру.

**🧠 Помнит вас**
Бот запоминает предпочтения между диалогами: вегетарианство и аллергии, что готовите только на плите без духовки, какая техника есть дома. В следующий раз не переспрашивает уже известное. Память можно стереть командой `/forget`.

Под ответами — кнопки: предложить ещё рецепт, заменить продукт, начать новый запрос, оценить ответ 👍/👎.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | начать заново |
| `/help` | справка |
| `/reset` | сбросить текущий диалог |
| `/forget` | забыть всё, что бот о вас запомнил |

## Как это устроено

```
Telegram → FastAPI (webhook)
   → распознавание речи (если голос)
   → подмешивание памяти о пользователе (mem0)
   → Router определяет тему
        ├── Кулинария: продукты → предпочтения → рецепты → замены
        └── Быт: категория → диагностика → [решение ‖ специалист ‖ профилактика]
```

Под капотом — система из нескольких специализированных «агентов», связанных в граф через **LangGraph**. Каждый агент отвечает за свой кусок логики, состояние диалога передаётся между ними. В бытовом пайплайне решение, совет по специалисту и профилактика считаются параллельно — так ответ собирается быстрее.

Долговременная память о пользователе вынесена в облачный **mem0**: перед ответом релевантные факты подмешиваются в промпт, после диалога сервис сам извлекает новые. Если ключ mem0 не задан — память просто отключается, бот работает как обычно.

## Технологии

- **Python 3.12**, FastAPI, aiogram 3
- **PostgreSQL** + SQLAlchemy (async) + Alembic
- **LangGraph** — оркестрация агентов
- **OpenRouter** (DeepSeek, с откатом на Claude Haiku) — основной LLM
- **Groq Whisper** — распознавание голоса
- **mem0** — долговременная память о пользователе
- Деплой: **Railway** + Docker

Провайдеры LLM и STT спрятаны за единым интерфейсом — поменять модель можно через `.env`, не трогая код.

## Запуск локально

Нужны: Python 3.12, [uv](https://github.com/astral-sh/uv), Docker.

```bash
# 1. Зависимости
uv sync

# 2. Конфигурация — заполните токены в .env
cp .env.example .env

# 3. База данных
docker compose up -d postgres
uv run alembic upgrade head

# 4. Запуск (локально — через polling)
uv run python -m src.dev
```

Для продакшна (webhook):

```bash
uv run uvicorn src.main:app --host 0.0.0.0 --port 8000
```

### Что положить в `.env`

| Переменная | Зачем |
|---|---|
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `OPENROUTER_API_KEY` | ключ для LLM ([openrouter.ai](https://openrouter.ai)) |
| `GROQ_API_KEY` | ключ для распознавания голоса ([groq.com](https://groq.com)) |
| `DATABASE_URL` | строка подключения к PostgreSQL |
| `MEM0_API_KEY` | память о пользователе ([app.mem0.ai](https://app.mem0.ai) → API Keys). Необязательно — пусто значит память выключена |
| `WEBHOOK_SECRET` | секрет для защиты webhook (для прода) |
| `BASE_URL` | публичный адрес сервиса (для прода) |

## Структура

```
src/
├── main.py        # FastAPI + webhook
├── dev.py         # локальный запуск через polling
├── config.py      # настройки
├── bot/           # aiogram: хендлеры, FSM, middlewares
├── agents/        # multi-agent граф (router + пайплайны)
├── llm/           # абстракция LLM + промпты
├── stt/           # распознавание речи
├── memory/        # долговременная память (mem0)
├── db/            # модели и репозитории
└── services/      # бизнес-логика
```
